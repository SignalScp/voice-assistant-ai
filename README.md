# 🎤 Мощный Голосовой Ассистент

## Описание

Продвинутый голосовой ассистент для Windows с поддержкой:
- 🗣️ Распознавание речи через микрофон (Google Speech Recognition)
- 🔊 Синтез речи (pyttsx3 с русским голосом)
- 🤖 Интеграция с OpenAI GPT для умных ответов
- ⚡ Выполнение системных команд
- 💬 Контекстная память разговора
- 🎯 Активация по ключевым словам

## Возможности

### Голосовые команды:
- **Открытие приложений**: "Открой браузер", "Открой YouTube", "Открой GitHub"
- **Время и дата**: "Сколько времени?", "Какое сегодня число?"
- **Поиск**: "Найди информацию про Python"
- **Системные**: "Выключи компьютер", "Отмена"
- **AI чат**: Любые вопросы и команды обрабатываются через GPT

### Ключевые слова активации:
- "ассистент"
- "помощник"
- "компьютер"

## Установка

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/SignalScp/voice-assistant-ai.git
cd voice-assistant-ai
```

### 2. Установите зависимости

**На Windows:**
```bash
pip install -r requirements.txt
```

**Для PyAudio могут потребоваться дополнительные шаги:**
- Скачайте подходящий wheel файл с [этого сайта](https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio)
- Установите: `pip install PyAudio‑0.2.14‑cp311‑cp311‑win_amd64.whl` (замените на вашу версию Python)

### 3. Настройте OpenAI API (опционально, но рекомендуется)

Для использования AI функций получите API ключ на [platform.openai.com](https://platform.openai.com/api-keys)

**Windows (PowerShell):**
```powershell
$env:OPENAI_API_KEY="your-api-key-here"
```

**Или добавьте в системные переменные окружения**

### 4. Настройте микрофон

Убедитесь, что микрофон подключен и настроен как устройство по умолчанию в Windows.

## Запуск

```bash
python assistant.py
```

## Использование

1. Запустите программу
2. Скажите слово активации: **"Ассистент"**, **"Помощник"** или **"Компьютер"**
3. Дождитесь ответа "Да, слушаю"
4. Произнесите команду или вопрос
5. Скажите **"Спасибо"** или **"Всё"** для перехода в режим ожидания
6. Скажите **"Выход"** или **"Стоп"** для завершения работы

## Примеры использования

```
Вы: "Ассистент"
Ассистент: "Да, слушаю"

Вы: "Открой YouTube"
Ассистент: "Открываю YouTube"

Вы: "Сколько времени?"
Ассистент: "Сейчас 15:30"

Вы: "Расскажи про машинное обучение"
Ассистент: [Ответ от GPT]

Вы: "Спасибо"
Ассистент: "Обращайтесь"
```

## Расширенная настройка

### Изменение параметров распознавания

В файле `assistant.py` можно настроить:
```python
self.recognizer.energy_threshold = 4000  # Порог чувствительности
self.engine.setProperty('rate', 180)      # Скорость речи
self.engine.setProperty('volume', 0.9)    # Громкость
```

### Добавление своих команд

Добавьте в метод `execute_command()` новые условия:
```python
if 'твоя команда' in command:
    # Ваш код
    return "Ответ ассистента"
```

## Технические детали

### Архитектура:
- **Распознавание речи**: Google Speech Recognition API
- **Синтез речи**: pyttsx3 с SAPI5 (Windows)
- **AI модель**: OpenAI GPT-3.5-turbo
- **Многопоточность**: Отдельный поток для озвучивания текста
- **Контекст**: История последних 10 сообщений

### Производительность:
- Время отклика: < 2 секунды
- Задержка распознавания: ~1 секунда
- Потребление памяти: ~100-150 MB

## Решение проблем

### Микрофон не работает
- Проверьте, что микрофон установлен как устройство по умолчанию
- Дайте разрешение Python на использование микрофона
- Попробуйте увеличить `energy_threshold`

### Не устанавливается PyAudio
- Используйте предкомпилированные wheel файлы
- Установите Visual C++ Build Tools

### AI не отвечает
- Проверьте наличие API ключа OpenAI
- Убедитесь, что есть интернет соединение
- Проверьте баланс API ключа
